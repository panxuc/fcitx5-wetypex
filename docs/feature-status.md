# 功能状态

本页按端到端验证程度标注功能：

- **可用**：已用真实原版核心和服务结果验证。
- **预览**：已接入原版实现，部分场景仍有已知限制。
- **不提供**：当前没有 Linux 实现。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 全拼 | 可用 | 原版候选、选词、部分选择和用户词频 |
| 双拼 | 可用 | 自然码、搜狗、微软、小鹤、拼音加加、紫光、智能 ABC |
| 五笔 | 可用 | 86、98、新世纪方案及五笔拼音混输 |
| 智能拼写 | 可用 | 原版纠错候选 |
| 表情与颜文字 | 可用 | 普通 emoji 与颜文字保持原样；微信专属表情仅在可识别的微信客户端推荐，原图来自用户本机准备的原版资源，见 [Linux 微信表情](wechat-emoticons.md) |
| 模糊拼音 | 可用 | 原版 19 组声母、韵母和易混读音开关 |
| 云候选 | 可用 | 联网且关闭单机模式时启用；云端新增候选带 ☁ 标记，结果变化主动推送到前端 |
| 中英文标点 | 可用 | 持久的“中文模式默认使用中文标点”偏好，`Ctrl + .` 在当前输入框临时切换 |
| 简繁、全半角 | 可用 | 由 Fcitx5 快捷键切换 |
| 常用语本地管理 | 可用 | 设置窗口中添加、编辑和删除，按输入码触发，内容按字面保存 |
| 日期、时间快捷输入 | 可用 | 日期七种格式（含农历）、时间四种格式；支持系统时区和 V 日期入口，见[日期、时间候选](date-time-input.md) |
| 官方设备配对 | 可用 | 真实六位匹配码、状态轮询与确认绑定 |
| 文字剪贴板同步 | 可用 | 与关联设备双向同步 |
| PNG 图片同步 | 可用 | 原始 PNG 二进制往返 |
| 个人词库同步 | 预览 | 原版同步器已接入，复杂冲突合并有限制 |
| 常用语同步 | 预览 | 原版同步器已接入，复杂冲突合并有限制 |
| 语音输入 | 可用 | 流式 PCM、原版 Opus/VAD/在线识别；实时预编辑、按住说话、取消和最终提交，见[流式语音输入](voice-input.md) |
| 语音标点与智能整理 | 可用 | 四种桌面端标点模式；智能整理映射到原版 aggressive polish |
| 问 AI | 可用 | 上下文触发、提问即时显示、完整回答与长内容滚动；短暂空响应自动重试，关闭窗口时清理未完成请求 |
| 隔空传送码 | 可用 | UUID、30 分钟二维码、对端轮询及关联设备邀请 |
| 隔空传送文件 | 可用 | 原版 Flurry 局域网与 WXP2P、关联设备主动邀请、进度、ACK 与落盘；与 Mac 的双向传输已实测，手机主动邀请尚待实机验证 |
| V 模式 | 可用 | `v` 后按空格打开快捷栏；英文前缀继续输入，明确算式进入原版计算 |
| 输入状态反馈 | 可用 | 中英、简繁图标与标签，语言、简繁、全半角及标点切换提示 |
| 原版运行时更新与回退 | 可用 | 兼容清单内版本的后台准备、空闲切换、回退与清理，见[运行时更新、回退与清理](runtime-updates.md) |
| 适配层自动更新 | 可用 | 每日从 GitHub Release 选择适合本机的最高完整正式版本，按 `SHA256SUMS` 校验后通过系统授权界面安装；Nix 由 Nix 配置更新 |
| Linux x86-64 | 可用 | 全部发行格式 |
| Linux ARM64 | 可用 | 原生 ARM64 CI 验证真实核心、TLS 与语音识别；物理 ARM 设备上的平板、实体键盘和麦克风体验尚未测试，见 [ARM64 支持](arm64.md) |
| 桌面悬浮工具栏 | 不提供 | Linux 桌面缺少可稳定实现的协议 |

云端能力由上游服务提供，服务可用性、账户限制和内容策略由上游决定。
