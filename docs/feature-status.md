# 功能状态

本页区分“界面存在”“协议可调用”和“端到端可用”。只有经过真实结果验证的能力才标记为可用。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 全拼 | 可用 | 原版候选、选词、部分选择和用户词频 |
| 双拼 | 可用 | 自然码、搜狗、微软、小鹤、拼音加加、紫光、智能 ABC |
| 五笔 | 可用 | 86、98、新世纪方案 |
| 智能拼写 | 可用 | 使用原版纠错能力 |
| 表情与颜文字 | 可用 | 原版候选开关 |
| 模糊拼音 | 可用 | 原版 19 组声母、韵母和易混读音开关 |
| 云候选 | 可用 | 仅在联网且非单机模式启用；云端新增候选带 ☁ 标记 |
| 简繁、标点、全半角 | 可用 | 由 Fcitx5 快捷键控制 |
| 常用语本地 CRUD | 可用 | 设置窗口支持添加、编辑和删除，并直接写入原版核心 |
| 官方设备配对 | 可用 | 真实六位码、状态轮询与确认绑定 |
| 文字剪贴板同步 | 可用 | 与关联设备双向同步 |
| PNG 图片同步 | 可用 | 原始 PNG 二进制往返 |
| 个人词库同步 | 预览 | 原版同步器已接入，复杂冲突合并仍有限制 |
| 常用语同步 | 预览 | 原版同步器已接入，复杂冲突合并仍有限制 |
| 语音输入 | 可用 | PipeWire、Opus、原版在线识别 |
| 语音标点与智能整理 | 可用 | 四种桌面端标点模式；智能模式采用相同的初始策略，整理映射到 aggressive polish 字段 |
| 问 AI | 可用 | 上下文触发、原版流式回答、继续提问；短暂空响应自动重试 |
| 隔空传送码 | 可用 | UUID、30 分钟二维码、对端轮询及关联设备邀请 |
| 隔空传送文件 | 可用 | 原版 Flurry LAN 与 WXP2P、官方二阶段调度、进度、ACK 与下载落盘；iPhone 图片传输已实机校验 |
| V 模式 | 可用 | 原版 VModeV2 候选，以及计算、剪贴板、常用语和符号快捷栏 |
| 桌面悬浮工具栏 | 不提供 | 当前没有稳定的 Linux 桌面协议实现 |
| 自动更新 | 可用 | 每日检查 GitHub Release，按发行版下载并校验包；通知中的安装按钮调用系统授权界面 |

云端接口由上游服务提供，服务可用性、账户限制和内容策略不由本项目控制。
