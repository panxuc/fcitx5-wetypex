# 配置参考

WeTypeX 的独立设置窗口（`fcitx5-wetypex-settings`）与 Fcitx5 配置页读写同一个文件：

```text
${XDG_CONFIG_HOME:-$HOME/.config}/fcitx5/wetypex.json
```

在 Fcitx5 配置工具中选择 WeTypeX 的“配置”，可以编辑输入方式、外观、设备同步和全部快捷键；同一页面还提供完整设置、账号与同步入口，采用与 Fcitx5 拼音词典管理器相同的 `ExternalOption` 扩展机制。修改后插件会重新加载输入后端。

Nix 用户可以通过 `defaultSettings` 为新用户预置这些字段，见[安装指南](installation.md#构建参数)。

## 输入

| 设置 | 说明 |
| --- | --- |
| 输入方式 | 全拼、七种双拼、三种五笔，JSON 字段 `input_mode`（`pinyin`、`double_pinyin`、`wubi`）。搜狗、微软、紫光双拼的组合内 `;` 优先作为 `ing` 编码，空组合时按标点处理。 |
| 五笔自动上屏 | “唯一候选自动上屏”：输入四码后只有一个候选时自动提交，不足四码或有重码时保留候选。“输入下一码时上屏”：第五码到来时提交前四码的首选，并把第五码作为下一组编码。两项可分别开关，适用于 86、98、新世纪及五笔拼音混输。 |
| 智能拼写 | 启用原版纠错候选。 |
| 表情和颜文字 | 控制原版 emoji、颜文字与符号候选。 |
| 微信表情 | 仅在可识别的微信客户端中推荐，候选显示原图，提交 Linux 微信支持的文本别名，见 [Linux 微信表情](wechat-emoticons.md)。 |
| 默认语言 | 首次启用以及从其他输入法切回 WeTypeX 时使用的中文或英文。切换窗口、输入框焦点或重新加载配置时保留手动选择的中英文、简繁和全半角状态。输入上下文的范围由应用决定，同一窗口的不同输入框可能共享状态。 |
| 中文模式默认使用中文标点 | 默认开启，字段 `chinese_punctuation`。关闭后，中文模式默认输入 `, . ! ?` 等英文标点。该设置与全半角相互独立，`Ctrl + .` 可在当前输入框中临时切换，见下文[中英文标点](#中英文标点)。 |
| 将「/?」按键替换为 、 | 默认开启，字段 `slash_punctuation`。输入中文时，`/` 键输入顿号。 |
| 符号自动转换 | 中文半角输入中，数字间的冒号、逗号和句号在后一个数字输入时转为 ASCII，例如 `3。14` → `3.14`。普通中文句号保持原样。 |
| 模糊拼音 | 原版 19 组模糊音，可独立开关。 |
| 自动添加中英文空格 | 默认关闭，字段 `auto_space`；开启后由 `auto_space_english` 与 `auto_space_digit`（两项默认开启）分别控制字母和数字。详见下文。 |
| 单机模式 | 字段 `standalone`。关闭云候选、设备同步、语音和问 AI 等联网能力；适配层与原版运行时的自动更新由“自动更新”开关单独控制。 |

### 自动添加中英文空格

只在 WeTypeX 活动输入上下文中处理汉字与 ASCII 字母、数字相邻的边界，例如 `你好Linux` → `你好 Linux`，`第5章` → `第 5 章`。标点、已有空白和纯中文不产生额外空格；需要保留紧凑数字格式时可单独关闭数字空格。

密码、敏感内容、网址、邮箱和数字专用输入框保持原文；语音和 V 模式显式插入的内容、日期时间格式也保持原文。不提供上下文文本的终端只短暂记录连续输入，光标移动、退格或应用快捷键后丢弃该记录。

## 外观

| 设置 | 取值 |
| --- | --- |
| 候选字号 | 10–18 |
| 每页候选 | 3–9，字段 `page_size` |
| 排列方式 | 横排或竖排，字段 `vertical` |
| 拼音显示位置 | “输入框内”（默认）或“候选框内”，字段 `preedit_position`，值为 `client` 或 `candidate`。客户端不支持内嵌预编辑或 Fcitx 禁用了内嵌预编辑时自动使用候选框。该设置同样作用于双拼和五笔。 |
| 候选序号样式 | “微信风格”（`1输入`，默认）或“Fcitx 默认”（由主题渲染 `1. 输入`），字段 `candidate_label_style`，值为 `wetype` 或 `fcitx`。只影响显示，数字选词与翻页按键不变。 |
| 主题 | 跟随系统、浅色、深色 |

外观设置会更新 Fcitx5 Classic UI 的 WeTypeX 主题项。其他输入法与 WeTypeX 共用 Classic UI，主题切换也会改变它们的候选窗口。希望由桌面主题统一管理时，Nix 用户可设置 `enableWeTypeTheme = false`。

设置窗口可拖动右下角调整大小，双击顶部最大化或恢复；首次打开时适配屏幕可用区域，内容溢出时出现滚动条。Qt 5.12 构建使用系统窗口边框拖动和缩放。

## 语音输入

| 设置 | 说明 |
| --- | --- |
| 麦克风 | “自动检测”使用当前默认输入源，也可指定 PipeWire 节点或 PulseAudio 音源。 |
| 标点设置 | 智能标点、添加完整标点、句末不加句号、空格替换标点，字段 `voice_punctuation`。 |
| 语音智能整理 | 交给原版引擎的 aggressive polish，字段 `voice_smart_polish`。 |
| 识别后复制到剪贴板 | 默认开启，字段 `voice_copy_to_clipboard`。仅复制当前聚焦会话确认接收的最终结果，详见[流式语音输入](voice-input.md#提交与剪贴板)。 |
| 快捷键 | 启动语音 `voice_launch_key`，按住说话 `voice_hold_key`，默认值见下表。 |

## 快捷键

快捷键使用 Fcitx5 原生的 `Key` / `List|Key` 类型，可在系统配置页直接捕获按键。

| 操作 | 默认按键 |
| --- | --- |
| 中英文切换 | `Shift` |
| 临时切换中英文标点 | `Ctrl + .`，仅中文模式 |
| 简繁切换 | 默认关闭，预设 `Ctrl + Shift + F` |
| 全半角切换 | 默认关闭，预设 `Shift + Space` |
| 候选翻页 | `-` / `=`、`[` / `]` |
| 问 AI | `=`，仅在没有组合输入时 |
| 启动语音 | `Ctrl + Win + Shift` |
| 按住说话 | `Ctrl + Win` |

单独按下并松开 `Shift` 切换中英文，按住 `Shift` 不会创建候选列表。中文半角模式下，`Shift + 字母` 把大写字母加入组合输入，由原版核心生成候选，支持 `AbC` 这样的大小写混合输入。修饰键、小键盘和各模式的完整规则见[按键与输入模式](input-handling.md)。

V 模式默认用于中文全拼：输入小写 `v` 后按空格打开快捷栏；继续输入 `vim`、`vscode`、`v2ray` 等英文时按普通编码处理，Enter 提交字面文本。输入 `v1+1`、`v0.1+0.2` 等明确算式后按空格选择结果。Fcitx5 配置页中的自定义 V 快捷键可直接打开快捷栏；默认绑定下，大写 `V` 以及双拼和五笔中的 `v` 保留为编码。

### 中英文标点

中文模式使用哪种标点由两层决定：

- **默认偏好**：“输入 → 中文模式默认使用中文标点”（字段 `chinese_punctuation`，默认开启），保存在配置中，对所有输入框生效。
- **临时切换**：在中文模式下按 `Ctrl + .`，只切换当前输入框的中英文标点，不写入配置。该输入框在下次修改默认偏好前保持切换后的状态。

修改默认偏好后，所有输入框立即恢复为新的偏好。英文模式下 `Ctrl + .` 交给应用处理。切换快捷键由字段 `punctuation_switch`（是否启用，默认开启）和 `punctuation_switch_keys`（按键，默认 `Ctrl + .`）控制。中英文标点与全角、半角设置相互独立。

## 输入状态提示

切换中英、简繁、全半角，以及中文状态下切换中英标点时，候选位置会短暂显示当前状态。面板支持时显示“中 / 英 / 繁”标签或对应图标，提示文字包含简繁、全半角和有效标点状态；旧版 Fcitx5 使用框架自带的输入法信息提示。

简繁切换保留仍在编辑的拼音及其光标位置；已选择的前半部分先按原选择上屏，剩余编码在新状态下继续。长按快捷键不会反复切换。旧配置中 `Control+Shift+f` 等大小写写法会按 Fcitx 规则规范化。

## 自定义常用语

在设置的“常用语和剪贴板 → 常用语”中添加内容及输入码，即可通过汉字、拼音或首字母触发，与普通候选一样选择。添加、修改和删除直接作用于原版核心的本地常用语，内容按字面保存。

例如把输入码设为 `zdy`、内容设为一句完整短句，之后输入 `zdy` 即可从候选中选择该句。

## 日期、时间快捷输入

中文全拼输入 `riqi`、`rq` 或 `date`，或 `shijian`、`sj`、`time`，首选保留原版普通词，第二项起提供当前日期或时间的多种格式；`v` 前缀形式（如 `vrq`）以格式为首选。完整说明见[日期、时间候选](date-time-input.md)。

## 设备同步

“跨设备剪贴板”“常用语同步”“个人词库同步”三个开关直接写入官方设备组功能位。尚未完成配对时，独立设置窗口禁用这些开关；切换失败时界面恢复服务器返回的状态。

## 自动更新

“升级和反馈”页的“有新版本时自动更新”（字段 `auto_update`，默认开启）同时控制原版运行时的兼容更新和适配层软件包更新，单机模式不影响该开关。同一页面提供“下载并更新原版核心”“回退上个版本”和“清理旧版本”。行为说明见[运行时更新、回退与清理](runtime-updates.md#自动更新)。

## 手工恢复

配置文件损坏时，先退出 Fcitx5，备份并移走 `wetypex.json`，再重新启动 Fcitx5；插件会以内置默认值创建新配置。重置界面设置只需处理这个文件，`account` 和 `state` 目录保存配对身份与用户词库，请保持原样。
