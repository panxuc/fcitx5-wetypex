# 配置参考

WeTypeX 的独立设置窗口与 Fcitx5 自带配置页共用：

```text
${XDG_CONFIG_HOME:-$HOME/.config}/fcitx5/wetypex.json
```

在 Fcitx5 配置工具中选择 WeTypeX 的“配置”，可以编辑输入方式、外观、设备同步和全部快捷键。修改后插件会重新加载输入后端。

## 输入

- 输入方式：全拼、七种双拼、三种五笔。搜狗、微软、紫光双拼组合内的 `;` 优先作为 `ing` 编码，空组合时仍按标点处理。
- 智能拼写：启用原版纠错候选。
- 表情和颜文字：控制原版 emoji、颜文字与符号候选。
- 微信表情：仅在能够识别的微信客户端中推荐，使用原版图片和 Linux 微信支持的文本别名；安装与 Wayland 应用识别范围见 [Linux 微信表情](wechat-emoticons.md)。
- 默认语言：首次启用以及从其他输入法明确切回 WeTypeX 时，使用配置的中文或英文。单纯切换窗口、输入框焦点或重新加载配置时，保留手动选择的中英文；简繁和全半角状态也继续保留。输入上下文的范围由应用决定，同一窗口的不同输入框可能共享状态。
- 符号自动转换：中文半角输入中，数字间的冒号、逗号和句号在后一个数字输入时转为 ASCII，例如 `3。14` → `3.14`。普通中文句号保持原样；关闭该选项、使用全角或英文标点时沿用对应模式。
- 模糊拼音：原版 19 组模糊音可独立开关。
- 单机模式：禁止云候选和设备同步相关联网。

## 外观

- 候选字号：10–18。
- 每页候选：3–9。
- 排列方式：横排或竖排。
- 拼音显示位置：默认“输入框内”，也可选择“候选框内”，在候选列表上方显示组合输入。客户端不支持内嵌预编辑或 Fcitx 禁用了内嵌预编辑时，自动使用候选框。两套设置界面共用 JSON 字段 `preedit_position`，值为 `client` 或 `candidate`；该选项也控制双拼、五笔等输入方式的预编辑位置。
- 候选序号样式：默认“微信风格”（`1输入`），也可选择“Fcitx 默认”（由主题渲染 `1. 输入`）。完整设置与 Fcitx5 配置页共用 JSON 字段 `candidate_label_style`，值为 `wetype` 或 `fcitx`。此选项只控制显示，数字选词与翻页按键保持一致。
- 主题：跟随系统、浅色、深色。

外观设置会更新 Fcitx5 Classic UI 的 WeTypeX 主题项。其他输入法共用同一个 Classic UI 时，主题切换也会影响其候选窗口。

## 语音输入

- 麦克风：默认“自动检测”使用当前默认输入源，也可指定 PipeWire 节点或 PulseAudio 音源。
- 标点设置：智能标点、添加完整标点、句末不加句号、空格替换标点，对应 `voice_punctuation`。
- 语音智能整理：把整理开关交给原版引擎的 aggressive polish，对应 `voice_smart_polish`。
- 识别后复制到剪贴板：默认开启，最终结果在提交给输入框的同时写入系统剪贴板，对应 `voice_copy_to_clipboard`。终端等只处理按键事件的窗口可能丢弃提交的文本，此时直接粘贴即可。设备剪贴板同步开启时，这份内容也会作为一次本地复制参与同步。
- 启动语音与按住说话的快捷键见下表，键位分别对应 `voice_launch_key` 和 `voice_hold_key`。

## 快捷键

快捷键使用 Fcitx5 原生 `Key` / `List|Key` 类型，可在系统配置页直接捕获。默认值包括：

| 操作 | 默认按键 |
| --- | --- |
| 中英文切换 | `Shift` |
| 中英文标点 | `Ctrl + .` |
| 简繁切换 | 默认关闭，预设 `Ctrl + Shift + F` |
| 全半角切换 | 默认关闭，预设 `Shift + Space` |
| 候选翻页 | `-` / `=`、`[` / `]` |
| AI 助手 | `=`，仅非组合状态 |
| 启动语音 | `Ctrl + Win + Shift` |
| 按住说话 | `Ctrl + Win` |

单独按下并松开 `Shift` 切换中英文；按住 `Shift` 本身不会创建候选列表。中文半角模式下，`Shift + 字母` 将大写字母加入组合输入，由原版核心生成候选，支持 `AbC` 这样的大小写混合输入；松开 `Shift` 保留当前组合。输入尚未返回候选时，空格和数字选词会按输入顺序进入后端队列。

V 模式入口仅用于中文全拼的空组合，小写 `v` 打开工具栏。需要在中文模式直接输入以 `v` 开头的英文时，可关闭 V 模式，或在 Fcitx5 配置页更改它的快捷键；大写 `V`、双拼和五笔中的 `v` 保留为编码。普通按键、自定义修饰键组合、小键盘及各模式的完整处理规则见[按键与输入模式](input-handling.md)。

## 自定义常用语

在设置的“常用语和剪贴板 → 常用语”中添加内容及输入码，即可通过汉字、拼音或首字母触发，按正常候选选词。添加、修改和删除直接作用于原版核心的本地常用语。

例如把输入码设为 `zdy`，内容设为常用的完整短句；输入 `zdy` 后从候选中选择该句。常用语内容按字面保存。

## 日期、时间快捷输入

中文全拼输入 `riqi`、`rq` 或 `date`，候选中会优先显示当前日期的七种格式，包括农历；输入 `shijian`、`sj` 或 `time`，会显示带日期的时间及纯时间，共四种格式。空格选择首项，数字或翻页选择其他格式，后面仍保留“日期”“时间”等普通候选。Enter 按原编码上屏，Esc 取消。

双拼按所选方案输入“日期”“时间”的编码，五笔按对应字形编码触发。中文全拼也可使用 `vriqi`、`vrq`、`vdate`、`vshijian`、`vsj`、`vtime`。英文模式中的字母照常直接输入。

日期和时间由原版核心生成，使用系统时区，也尊重显式设置的 `TZ`；每次重新输入会刷新，选词提交的是屏幕上那次候选的值。实现依据见[日期、时间候选](date-time-input.md)。

## 设备同步

三个同步开关会直接写入官方设备组功能位。没有完成配对时，独立设置窗口会禁用这些开关。切换失败时界面恢复服务器返回的原状态。

## 自动更新

开启“有新版本时自动更新”后，WeTypeX 每天检查一次 GitHub Release。发现新版本时，会为 Arch、Debian/Ubuntu 或 Fedora 下载对应软件包并核对发布页中的 SHA-256；桌面通知的“安装更新”按钮随后调用系统授权界面完成升级。关闭开关会停止后台检查。

旧版 `notify-send` 不支持操作按钮时，使用普通通知显示已校验软件包的完整路径，便于手动安装。

## 手工恢复

配置损坏时先退出 Fcitx5，备份并移走 `wetypex.json`，再重新启动。插件会使用内置默认值创建新配置。不要为了重置界面删除 `account` 或 `state`，否则会丢失配对身份和用户词库。
