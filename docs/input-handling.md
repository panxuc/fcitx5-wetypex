# 按键与输入模式

以下规则适用于已激活且有焦点的 WeTypeX 输入上下文。密码框不参与编码、候选、语音或快捷键处理。系统或应用提前截获的按键不会到达输入法。

## 模式决定编码

`input_mode` 是当前模式的唯一依据，值为 `pinyin`、`double_pinyin` 或 `wubi`。旧配置没有这个字段时，`keyboard=5` 作为五笔模式读取；其余情况使用全拼。新旧字段同时存在时以 `input_mode` 为准，发送给核心的键盘类型也从这个模式生成。

五笔 86、98、新世纪分别使用原版对应的单字表。它们在原版 C 接口中共用字典类型，不能同时注册到同一份资源中；宿主在创建会话前选择所需表，原有会话继续保留其资源快照。现有完整运行时无需重新下载或删改字典，拼音和词组资源照常保留。

| 输入状态 | 字母 | `v` | `'` | `;` |
| --- | --- | --- | --- | --- |
| 中文全拼 | 进入原版核心，包括 Shift 产生的大写字母 | 空组合且启用 V 模式时打开工具栏；组合内作为字母 | 组合内为音节分隔符；空组合为引号 | 标点；开启分号选词时选择第二候选 |
| 中文双拼 | 按所选七种方案之一进入核心 | 作为双拼编码，不打开 V 工具栏 | 组合内为音节分隔符；空组合为引号 | 搜狗、微软、紫光方案的组合内优先作为 `ing` 编码；其他情况按标点或选词配置处理 |
| 中文五笔 | 按 86、98 或新世纪方案进入核心，拼音混输由对应开关控制 | 作为五笔编码，不打开 V 工具栏 | 引号，不作为拼音分隔符 | 标点或配置的选词键 |
| 英文 | 直接交给应用；全角模式转换可打印 ASCII | 普通字母 | 按引号配对、全角设置处理 | 普通符号或全角符号 |
| V 工具栏、计算器 | 按工具菜单或原版计算器规则处理 | 再按入口键可取消 | 计算器输入 | 计算器输入 |

中文编码按半角状态说明。中文全角状态下，空组合的大写字母、数字和空格直接转换成全角字符，小写字母仍可开始编码；英文全角状态转换全部可打印 ASCII。

开启“分号、引号选择第 2、3 位”时，组合内的 `'` 用于选第三候选，优先于音节分隔符。搜狗、微软、紫光双拼的无修饰键 `;` 仍优先作为编码。显式配置的“第二候选”“第三候选”按对应操作执行，例如把分号配置成第三候选时不会误选第二个；双拼编码优先规则仍适用。

## 组合编辑与选词

| 按键 | 中文组合内 | 没有组合时 |
| --- | --- | --- |
| 空格 | 选择当前候选；没有候选时提交原始输入 | 交给应用；全角时输入全角空格 |
| `1`–`9`、数字小键盘 `1`–`9` | 选择当前页对应候选 | 交给应用；全角时转换数字 |
| `0`、数字小键盘 `0` | 不作为第十候选；交给应用 | 交给应用；全角时转换数字 |
| Enter、数字小键盘 Enter | 提交原始输入；V 计算器有结果时选择结果 | 交给应用 |
| Esc | 取消当前组合或工具菜单 | 交给应用 |
| 左右、Home、End | 移动组合内的可编辑光标 | 交给应用 |
| Backspace、Delete | 编辑组合输入 | 交给应用 |
| 上下 | 移动当前候选 | 交给应用 |
| PageUp、PageDown | 候选翻页 | 交给应用 |
| `-`/`=`、`[`/`]`、`,`/`.`、Tab/Shift+Tab | 仅在对应翻页开关启用时翻页 | 按标点、AI 或应用规则处理 |

小键盘数字按其实际数字键符号识别；NumLock 关闭后产生的导航键不作为数字选词。实现直接识别小键盘数字范围，不依赖 Fcitx 5.0.20 才加入的小键盘 `isDigit()` 行为。

开启符号自动转换的中文半角状态中，无组合的数字按字面文本输入，与标点通过同一通道按顺序送入应用，不作为编码或选词。数字间的 `：`、`，`、`。` 在后一个数字到来时转为 ASCII；客户端异步更新文本时，确认对应的数字片段后补做转换，不阻塞后续按键。

已配置的快捷键先处理。例如启用 Shift+Space 全半角切换后，它执行切换；未绑定其他操作的 Shift+Space 在组合内仍按空格选词。

自动符号配对优先使用客户端的带光标提交能力。Wayland-v2 不支持该能力时，按符号、方向键和后续输入的顺序处理；按住 Shift 时，光标移动等待真实修饰键释放。能读取周边文本时确认光标更新，不能读取时给客户端一帧时间处理方向键，再处理排队输入。普通编码输入、Wayland-v1 和 D-Bus 不增加这段等待。取消、显式导航、应用快捷键、失焦或重置会撤销待处理的自动移动。

自动跳过已有右括号需要客户端提供周边文本；不提供文本的客户端仍按普通右括号输入处理，避免猜测并跳过其他位置的文字。

空格或数字紧跟在快速输入后、候选尚未返回时，选择操作按原有输入顺序排队。选词提交完成前到达的后续按键也排队处理。

修改编码、移动组合光标或选完一段前缀后，候选页码和高亮位置回到开头。单纯收到云候选刷新时保留当前翻页位置。

## 修饰键与自定义快捷键

- 单独按下再松开 Shift 切换中英文；按住 Shift 输入字母产生大写编码，松开后不切换。左右 Shift 均可使用。Ctrl 单键切换由独立开关控制。
- 用于切换语言的修饰键仍把原始按下和松开事件交给应用，保留 Shift+Tab、Shift+方向键等快捷键。选词或光标操作后的内部按键重放不会再次发送这些物理事件。
- 一侧 Shift 松开时另一侧仍按着，不作为单键切换；交替使用左右 Shift 也不会把已输入的文字切到另一种语言。
- Ctrl+Shift、Alt+Shift 等组合不隐式触发单键 Shift 切换；需要时可在中英文切换键中明确配置。纯修饰键组合在松开时触发，期间输入了其他键则取消切换。
- F8 等普通切换键在按下时触发一次，长按重复事件不反复切换。切换时已有组合先按原始文字提交，后续输入使用切换后的语言。
- 自定义选词、翻页键可带 Ctrl、Alt 等修饰键，且仅在中文组合或工具菜单中生效。左右 Ctrl 选第二、第三候选由独立开关控制；组合内选词优先于 Ctrl 单键切换。
- 没有绑定为输入法操作的 Ctrl、Alt、Super、Meta、Hyper 组合交给应用。Shift 本身不阻止字母编码；CapsLock 产生的大写字母同样进入核心。
- 中英标点、简繁、全半角切换依照各自开关和配置按键执行。V 工具入口仅用于中文全拼。AI 入口需联网、开启且当前没有组合并有可用上下文。

## 语音输入

联网且开关启用时，默认 `Ctrl+Win+Shift` 启停语音，`Ctrl+Win` 按住说话。启动前的组合先提交原始文字。按住说话在配置组合中的按键松开时结束，未绑定的其他键松开不影响录音。

语音期间，空格结束录音，Enter 请求立即结束并上屏，Esc 取消；其余非修饰键取消语音后继续按正常输入或应用快捷键处理。语音结果只提交给仍有焦点的原输入上下文。
