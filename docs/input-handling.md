# 按键与输入模式

本文是 WeTypeX 按键处理的完整参考，适用于已激活且有焦点的 WeTypeX 输入上下文。密码输入框不参与编码、候选、语音或快捷键处理；系统或应用提前截获的按键不会到达输入法。默认快捷键与配置字段见[配置参考](configuration.md)。

## 模式决定编码

`input_mode` 是当前输入方式的唯一依据，取值为 `pinyin`、`double_pinyin` 或 `wubi`，发送给原版核心的键盘类型也由它生成。旧配置没有该字段时，`keyboard=5` 按五笔读取，其余按全拼读取；新旧字段同时存在时以 `input_mode` 为准。

五笔 86、98、新世纪分别使用原版对应的单字表。它们在原版 C 接口中共用同一字典类型，因此宿主在创建会话前选择所需的表，已有会话保留其资源快照。切换五笔方案无需重新下载或修改词典。

| 输入状态 | 字母 | `v` | `'` | `;` |
| --- | --- | --- | --- | --- |
| 中文全拼 | 进入原版核心，包括 Shift 产生的大写字母 | 先作为编码；单独 `v` 后按空格打开快捷栏，英文前缀继续输入，明确算式进入计算 | 组合内为音节分隔符，空组合时为引号 | 标点；开启分号选词时选择第二候选 |
| 中文双拼 | 按所选方案进入核心 | 作为双拼编码，不打开快捷栏 | 组合内为音节分隔符，空组合时为引号 | 搜狗、微软、紫光方案的组合内优先作为 `ing` 编码，其他情况按标点或选词配置 |
| 中文五笔 | 按 86、98 或新世纪方案进入核心，拼音混输由对应开关控制 | 作为五笔编码，不打开快捷栏 | 引号 | 标点或配置的选词键 |
| 英文 | 半角模式可开启英文单词补全，全角模式转换可打印 ASCII | 普通字母 | 补全组合中可输入撇号，其余按引号配对和全角设置处理 | 普通符号或全角符号 |
| V 快捷栏、计算器 | 按快捷栏菜单或原版计算器规则处理 | 再按入口键关闭 | 计算器输入 | 计算器输入 |

上表描述中文半角状态。中文全角状态下，空组合的大写字母、数字和空格直接转为全角字符，小写字母仍开始编码；英文全角状态转换全部可打印 ASCII。

开启“分号、引号选择第 2、3 位”时，组合内的 `'` 选择第三候选，优先于音节分隔符；搜狗、微软、紫光双拼的无修饰键 `;` 仍优先作为编码。显式配置的“第二候选”“第三候选”按配置执行，例如把分号配置为第三候选时选择第三个。

### V 模式

默认 V 入口不抢占首字母：`vim`、`vscode` 和 `v2ray` 直接编码，`v` 后按空格打开快捷栏，`v1+1` 等带运算符的表达式进入计算，版本号可用 Enter 按字面提交。计算器中的数字与运算符优先作为表达式，不触发普通候选的数字选词或 `-`/`=` 翻页。空计算器中按退格返回 `v`，按 Enter 或 Delete 不修改应用中的正文。自定义入口键直接打开快捷栏。

## 组合编辑与选词

| 按键 | 中文组合内 | 没有组合时 |
| --- | --- | --- |
| 空格 | 选择当前候选；没有候选时提交原始输入 | 交给应用；全角时输入全角空格 |
| `1`–`9`、小键盘 `1`–`9` | 选择当前页对应候选 | 交给应用；全角时转换数字 |
| `0`、小键盘 `0` | 交给应用（不作为第十候选） | 交给应用；全角时转换数字 |
| Enter、小键盘 Enter | 提交原始输入；V 计算器有结果时选择结果 | 交给应用 |
| Esc | 取消当前组合或快捷栏菜单 | 交给应用 |
| 左右、Home、End | 移动组合内的编辑光标 | 交给应用 |
| Backspace、Delete | 编辑组合输入 | 交给应用 |
| 上下 | 移动当前候选 | 交给应用 |
| PageUp、PageDown | 候选翻页 | 交给应用 |
| `-`/`=`、`[`/`]`、`,`/`.`、Tab/Shift+Tab | 对应翻页开关启用时翻页 | 按标点、问 AI 或应用规则处理 |

修改编码、移动组合光标或选完一段前缀后，候选页码和高亮回到开头；单纯收到云候选刷新时保留当前翻页位置。

### 小键盘

小键盘数字按实际数字键符号识别；NumLock 关闭后产生的导航键不用于选词。该识别直接判断小键盘数字范围，不依赖 Fcitx 5.0.20 才加入的小键盘 `isDigit()` 行为。小键盘方向、Home/End、PageUp/PageDown、Delete、空格和 Tab 与对应普通按键行为一致。

小键盘的 `+`、`-`、`*`、`/`、小数点、分隔符和 `=` 按字面符号输入；在中文组合内先提交首选再插入符号，符号不会出现在拼音之前。全角状态下使用对应全角符号。小键盘符号不触发默认的 `-`/`=` 或逗号/句号翻页，显式配置的快捷键仍然优先；在 V 计算器中继续作为算式输入。

### 输入顺序

快速输入后紧跟的空格或数字会在候选返回前按原顺序排队，选词提交完成前到达的后续按键也会排队。选词、标点、Enter 原文提交和简繁切换都等待核心确认组合状态后再处理后续按键；五笔四码唯一上屏和下一码顶字遵循同样的顺序。因此快速连按数字不会误选旧候选或丢失。

选词后紧接标点时，文字和标点作为一次插入提交，避免部分 Wayland 客户端只保留同一批更新中的最后一段文字。括号光标移动后的连续文本同样合并提交，并在插入前处理其中的退格和数字标点转换；嵌套括号逐层跟踪自动生成的右括号。

### 数字与标点

开启符号自动转换的中文半角状态中，无组合时的数字按字面输入，与标点按顺序送入应用。数字间的 `：`、`，`、`。` 在后一个数字到来时转为 ASCII；客户端异步更新文本时，确认对应的数字片段后再补做转换，不阻塞后续按键。

应用不提供周边文本（例如部分浏览器和终端）时，数字后的句点、逗号和冒号直接使用 ASCII，其他标点继续遵循中英文及全半角设置。应用快捷键和导航操作会结束当前数字标点状态。退格、Delete、方向键和 Home/End 会等待正在进行的小数转换确认后再执行。

## 自动配对标点

自动配对标点后，光标需要回到成对符号之间。WeTypeX 优先使用客户端的带光标提交能力；Wayland text-input-v2 或 GNOME 的 IBus 路径不支持该能力时，按符号、方向键和后续输入的顺序处理。

- 按住 Shift 时，光标移动等待真实修饰键释放；排队的符号视为修饰键组合，释放 Shift 不会被误判为切换语言。
- IBus 方向键同时提供 Linux evdev 对应的 XKB 键码（evdev + 8）和按下、释放事件，GNOME 不会收到键码为零的事件。
- 能读取周边文本时确认光标更新后再继续；不能读取时给客户端一帧时间处理方向键，再处理排队输入。
- GNOME/IBus 路径中，拼音选词后紧接配对标点时，选词文字和标点合并上屏，光标偏移包含前缀的 Unicode 字符数。
- 不提供周边文本的 D-Bus 客户端在自动配对后按顺序回放按键，应用处理完编辑和导航动作后再提交后续文字。
- 取消、显式导航、应用快捷键、失焦或重置会撤销待处理的自动移动。已转发但尚未释放的 IBus 按键在物理释放、失焦、重置或后端重启时补齐释放事件，Tab 或修饰键不会保持按下状态。

自动跳过已有右括号需要客户端提供周边文本；其他客户端把右括号作为普通输入处理。

前端既不支持带光标提交、也不处理转发的方向键时，光标无法回移。例如 fcitx5-gtk 5.1.3 的 GTK4 模块中 `_fcitx_im_context_forward_key_cb` 是空实现；这需要在对应前端中修复，增加等待时间无法解决。

## 修饰键与自定义快捷键

- 单独按下再松开 Shift 切换中英文；按住 Shift 输入字母产生大写编码，松开后不切换。左右 Shift 均可使用。Ctrl 单键切换由独立开关控制。
- 用于切换语言的修饰键仍把原始按下和松开事件交给应用，Shift+Tab、Shift+方向键等快捷键照常可用。选词或光标操作后的内部按键重放不会再次发送这些物理事件。
- 一侧 Shift 松开时另一侧仍按着，不触发单键切换；交替使用左右 Shift 不会把已输入的文字切到另一种语言。
- Ctrl+Shift、Alt+Shift 等组合不会隐式触发 Shift 单键切换，需要时可在中英文切换键中明确配置。纯修饰键组合在松开时触发，期间按了其他键则取消切换。
- F8 等普通切换键在按下时触发一次，长按不重复切换。切换时已有组合先按原始文字提交，后续输入使用切换后的语言。
- 自定义选词、翻页键可以带 Ctrl、Alt 等修饰键，只在中文组合或快捷栏菜单中生效。左右 Ctrl 选择第二、第三候选由独立开关控制；组合内选词优先于 Ctrl 单键切换。
- 已配置的快捷键优先处理。例如启用 Shift+Space 全半角切换后，它执行切换；未绑定其他操作时，组合内的 Shift+Space 按空格选词。
- 没有绑定为输入法操作的 Ctrl、Alt、Super、Meta、Hyper 组合交给应用。Shift 本身不阻止字母编码；CapsLock 产生的大写字母同样进入核心。
- 中英标点、简繁、全半角切换依照各自的开关和按键执行，只在首次按下时切换并刷新面板和提示。V 入口仅用于中文全拼。问 AI 需要联网、开启该功能、当前没有组合输入并有可用的上下文。

## 中英文标点

中文模式默认使用的标点由偏好“中文模式默认使用中文标点”（字段 `chinese_punctuation`）决定。中文模式下按 `Ctrl + .` 临时切换当前输入框的中英文标点，不修改偏好；切换会结束正在进行的数字标点转换，并在候选位置提示新的状态。英文模式下该快捷键交给应用。修改偏好后，所有输入框回到新的默认值。中英文标点与全半角分别设置、分别切换。完整说明见[配置参考](configuration.md#中英文标点)。

## 语音输入

联网且开启语音时，默认 `Ctrl+Win+Shift` 启停语音，`Ctrl+Win` 按住说话。启动前的组合输入先按原始文字提交。按住说话在配置组合中的按键松开时结束，其他未绑定键的松开不影响录音。

语音期间，空格结束录音，Enter 立即结束并上屏，Esc 取消；其余非修饰键取消语音后按正常输入或应用快捷键处理。语音结果只提交给仍有焦点的原输入上下文。更多说明见[流式语音输入](voice-input.md)。
